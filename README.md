# Equipment Health and Failure-Risk Analytics for Industrial Operations

A portfolio project by **Sai Bhaskar Chundru**, combining Mechanical Engineering knowledge with Data Analytics to explore equipment health and failure patterns.

## Project overview

This project investigates how operating measurements such as temperature, rotational speed, torque and tool wear relate to recorded equipment failures. It brings together data-quality checks, exploratory analysis, SQL queries, machine-learning classification and a Tableau dashboard.

## Tools and workflow

- **Python and pandas:** inspect, prepare and explore operational data.
- **SQL:** answer equipment-health questions through aggregate queries.
- **Scikit-learn:** compare a no-failure baseline, logistic regression and random forest.
- **Tableau:** present operating conditions and failure summaries in a dashboard.

## Dataset and scope

The project uses the synthetic **UCI AI4I 2020 Predictive Maintenance Dataset** as an educational case study. It demonstrates an analytical workflow; applying it in industry would require validation with real equipment data.

Raw data and private learning notes are excluded from GitHub.
